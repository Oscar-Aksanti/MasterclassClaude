# Exercice guidé — Module 6 — Positionner 3 profils, puis le vôtre

**Durée : 20-25 minutes, en session (bloc pratique guidée).**

## Partie A — Repositionnez les 3 mini-cas dans la grille de décision

Reprenez les 3 profils présentés dans `../07-etude-de-cas.md` (Abdoulaye le salarié, Nadia la freelance débutante, Karim l'entrepreneur). | Profil | Temps disponible/semaine (faible/moyen/élevé) | Tolérance au risque (faible/moyenne/élevée) | Besoin de revenu immédiat (oui/non) | Voie que je recommande | Pourquoi (1 phrase) |
|---|---|---|---|---|---|
| Abdoulaye Sow | | | | | |
| Nadia Traoré | | | | | |
| Karim Fofana | | | | | |

Comparez ensuite vos réponses avec l'analyse comparative de `../07-etude-de-cas.md` — l'objectif n'est pas de deviner la "bonne" réponse mais de vous entraîner à repérer les critères déterminants avant de les appliquer à votre propre cas dans la Partie B.

## Partie B — Positionnez-vous vous-même

Répondez honnêtement, sur VOTRE situation réelle aujourd'hui (pas celle que vous aimeriez avoir dans un an) :

1. **Temps disponible par semaine** en dehors de mes obligations actuelles, pour une activité de valorisation IA : ______________________
2. **Tolérance au risque financier** aujourd'hui (faible / moyenne / élevée), et pourquoi : ______________________
3. **Besoin de revenu immédiat** (dans les 90 jours) : oui / non — si oui, pourquoi précisément : ______________________
4. **Voie que je choisis en priorité** (salariat augmenté / freelance / produit digital) : ______________________

## Partie C — Premier jet de pitch ou d'offre

Selon la voie choisie en Partie B, rédigez un premier jet (5-10 minutes, ne cherchez pas la perfection) :

- Si **salariat augmenté** : ébauchez les 4 blocs du pitch interne (problème / solution Claude / gain chiffré / prochaine étape) pour un projet pilote dans votre service.
- Si **freelance** : rédigez en 2-3 phrases l'offre que vous proposeriez à un client existant, en langage résultat (pas "je fais de l'IA").
- Si **produit digital** : identifiez le savoir-faire que vous transformeriez en produit, et le format le plus rapide à construire (template, pack de prompts, mini-formation, automatisation en marque blanche).
