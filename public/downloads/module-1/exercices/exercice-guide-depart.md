# Exercice guidé — Module 1 — Quel outil pour quelle tâche ?

**Durée : 15-20 minutes, en session (bloc pratique guidée).**

## Partie A — Associez chaque tâche au bon outil Claude

Pour chacune des 5 tâches ci-dessous, indiquez l'outil que vous utiliseriez (Claude.ai / Claude Code / Claude Cowork / Claude in Chrome) et justifiez en une phrase. Ces tâches sont inspirées du quotidien de Fatou — adaptez mentalement à votre propre métier si besoin.

| # | Tâche | Outil choisi | Justification (1 phrase) |
|---|---|---|---|
| 1 | Rédiger un email de relance à un client qui n'a pas payé sa facture depuis 3 semaines | | |
| 2 | Nettoyer et analyser un fichier Excel de 500 lignes de ventes pour en sortir 3 recommandations | | |
| 3 | Construire un tableau de bord web pour visualiser les ventes d'un client | | |
| 4 | Rechercher les tarifs pratiqués par 5 consultants concurrents sur leurs sites web respectifs | | |
| 5 | Suivre un projet client sur plusieurs semaines, avec des tâches, des échéances et des rappels | | |

## Partie B — Votre checklist d'environnement (à cocher au fur et à mesure)

- [ ] Claude Code installé (`claude --version` répond avec un numéro de version)
- [ ] Une première commande simple exécutée avec succès dans Claude Code
- [ ] Une Skill personnelle créée à partir d'UNE tâche que vous refaites chaque semaine
- [ ] La Skill testée sur un exemple réel
- [ ] Un connecteur MCP connecté (Google Drive recommandé)
- [ ] Le connecteur MCP testé avec succès (Claude retrouve/utilise une information sans que vous l'ayez copiée-collée)
- [ ] Un fichier de mémoire personnelle créé (voir gabarit dans `../09-ressources-telechargeables/gabarit-memoire-personnelle.md`)

## Partie C — Votre Skill personnelle

Avant de la créer, répondez à ces 3 questions (elles évitent de perdre du temps à improviser en direct) :

1. Quelle tâche est-ce que je refais, à l'identique dans sa structure, au moins une fois par semaine ?
2. Quel est le résultat exact que je veux obtenir chaque fois (les sections, le ton, le format) ?
3. Quelle erreur est-ce que je veux éviter que Claude fasse (ex. inventer une information absente) ?

Une fois répondu, utilisez ces réponses pour formuler votre demande de création de Skill à Claude Code (voir la formulation utilisée dans `../05-demo-commentee.md`, sous-bloc B).
