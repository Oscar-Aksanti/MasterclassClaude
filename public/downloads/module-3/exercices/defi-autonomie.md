# Défi en autonomie — Module 3

**À faire avant la Session 4 (lundi 24 août 2026).** Ce défi n'est pas optionnel : le Module 4 réutilise directement le fichier nettoyé de ce module pour construire un dashboard Streamlit — sans lui, vous démarrez le Module 4 avec un handicap.

## Votre mission

1. **Finalisez le nettoyage complet** de `ventes-delta-distribution-brut.xlsx` si vous n'avez pas terminé en session — les 5 types de défauts (doublons, valeurs manquantes, formats de région, dates mélangées, valeurs aberrantes) doivent être traités, pas seulement une partie.
2. **Rédigez les 3 insights business** avec vos propres chiffres (rupture Nord, croissance E-commerce, retards de livraison) — comparez-les à `exercice-guide-solution.md` pour vérifier que l'ordre de grandeur est cohérent.
3. **Produisez une visualisation exportable** (Power BI, Google Sheets ou Looker Studio) qui illustre au moins l'insight de la rupture Nord — un graphique en courbe de la quantité vendue par mois dans le Nord, à minima.
4. **Option pour aller plus loin (niveau 2, non obligatoire)** : demandez à Claude Code de reproduire le même nettoyage en pandas, et comparez le résultat à votre nettoyage Excel — est-ce que vous obtenez exactement le même nombre de lignes et les mêmes totaux ?
5. **Sur votre propre contexte professionnel**, si vous avez un jeu de données réel disponible (ventes, budget, suivi d'activité, base clients) : refaites l'exercice complet — diagnostic, nettoyage, 3 insights — sur vos propres données plutôt que sur celles de DELTA. Si vous n'avez pas de jeu de données personnel exploitable, continuez avec le fichier DELTA, c'est un livrable tout aussi valide pour la certification.
6. **Postez** votre visualisation (capture d'écran ou lien) dans la communauté privée, canal `#par-module`, avec vos 3 insights rédigés en une phrase chacun.

## Pourquoi ce défi précisément

Le Module 4 vous demande de construire un dashboard Streamlit à partir d'un fichier de données déjà propre — impossible de le faire sereinement si le nettoyage de ce module reste à moitié fait. Le fichier `ventes-delta-distribution-nettoye.xlsx` que vous produisez ici est un input direct de la session suivante.

## Si vous êtes bloqué

- Rejoignez la communauté privée et posez votre question dans `#entraide` — quelqu'un d'autre a probablement le même blocage sur le même type de défaut.
- Relisez `04-lecon-ecrite-complete.md`, Partie 1 (nettoyage) ou Partie 4 (rédaction des insights) selon où vous êtes bloqué.
- Ce n'est pas grave d'arriver à la Session 4 avec un insight moins précis que le corrigé — mais arrivez avec un fichier réellement nettoyé (zéro doublon, zéro valeur manquante), c'est le socle indispensable du Module 4.

## Une fois terminé

Cochez la checklist complète dans `01-fiche-pedagogique.md` (section Livrable attendu) et ajoutez votre fichier nettoyé, vos 3 insights et votre visualisation à la **Section 3 de votre Portfolio IA Professionnel** (voir `01-programme/parcours-portfolio-participant.md`).
