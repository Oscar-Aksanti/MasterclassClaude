# Fiche pédagogique — Module 1 — Maîtriser l'écosystème Claude : les fondations du Top 1 %

**Session 1 · Lundi 17 août 2026 · 18h00–19h45 GMT · Teams**

## Objectifs pédagogiques

À la fin de cette session, chaque participant est capable de :

1. **Choisir** le bon outil Claude (Claude.ai, Claude Code, Claude Cowork, Claude in Chrome) selon la nature d'une tâche, sans hésitation ni essai-erreur.
2. **Installer et utiliser** Claude Code pour une tâche simple.
3. **Créer une Skill** personnelle minimale et l'invoquer.
4. **Connecter un serveur MCP** (Google Drive) et l'utiliser dans une conversation.
5. **Expliquer avec ses propres mots** ce qu'est une fenêtre de contexte et pourquoi démarrer une nouvelle conversation au bon moment améliore la qualité des réponses.

## Prérequis

- Aucune connaissance technique préalable.
- Un compte Claude.ai actif (le mois d'accès inclus doit être activé avant cette session — voir `communaute-privee/message-onboarding.md`).
- Un ordinateur Mac ou Windows avec droits d'installation de logiciel (pas un poste d'entreprise verrouillé, sauf si le participant a vérifié pouvoir installer un outil en ligne de commande).
- Un compte Google (gratuit) pour la démonstration MCP.

## Matériel nécessaire côté participant

- Ordinateur portable, connexion stable.
- Terminal disponible (Terminal sur Mac, Terminal/PowerShell sur Windows — l'installation ne demande pas d'expérience en ligne de commande, juste de copier-coller 2-3 commandes).
- Le fichier `06-exercices/exercice-guide-depart.md` ouvert avant la session.

Cette session introduit **Fatou Diallo** (voir `01-programme/parcours-portfolio-participant.md`) et sa situation de départ : consultante indépendante débordée par des tâches répétitives à faible valeur. ## Livrable attendu

**Un environnement Claude configuré**, matérialisé par une checklist cochée :

- [ ] Claude Code installé et fonctionnel (une commande exécutée avec succès)
- [ ] Une Skill personnelle créée (fichier `SKILL.md` minimal) et invoquée au moins une fois
- [ ] Un serveur MCP connecté (Google Drive recommandé) et interrogé au moins une fois avec succès
- [ ] Un fichier de mémoire/contexte personnel initialisé (voir gabarit dans `09-ressources-telechargeables/`)
- [ ] Capture d'écran de l'ensemble postée dans la communauté privée, canal `#par-module`

Critères de complétion détaillés : `10-grille-evaluation-livrable.md`.

## Erreurs fréquentes à anticiper (côté animateur)

- **Peur de "casser quelque chose"** en installant un outil en ligne de commande : rassurer explicitement — installer Claude Code ne touche à rien d'autre sur la machine, c'est un programme isolé comme un autre.
- **Confusion Claude.ai / Claude Code** : beaucoup de participants pensent que Claude Code est "la version pour développeurs" et s'auto-excluent. Insister dès la première minute : Claude Code écrit et exécute, le participant décrit — aucune ligne de code à taper soi-même.
- **Blocage sur les autorisations MCP** (pop-up de connexion Google qui semble suspect à un public peu familier des OAuth) : montrer explicitement à quoi ressemble l'écran d'autorisation légitime avant que les participants ne le rencontrent seuls.
- **Sous-estimer l'intérêt des Skills** ("je n'ai qu'une tâche répétitive, ça vaut le coup ?") : ancrer sur le calcul simple fait dans la démo (temps perdu par semaine × 52).
